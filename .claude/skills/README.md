# StageVerse department skills

The backend of StageVerse is organised like a real touring production office. Each skill is one office; each office holds the departments a top-level world tour has.

| Skill | Departments |
| --- | --- |
| `stage-creative-director` | Creative director, set and stage design (PR #4) |
| `show-design-departments` | Lighting designer, video director and IMAG, screens content, wardrobe and glam, special effects and lasers |
| `tour-production-office` | Tour manager, production manager, stage manager and show caller, audio, rigging and staging, crowd, security and venue operations |
| `artist-management-office` | Artist manager, booking agent and routing, promoter and ticketing, business manager and settlement, marketing and PR, merchandise, VIP and fan club, legal and business affairs |
| choreographer (separate work) | Choreography mapped to each song's tempo, blocking across main stage, runway and B-stage, background dancers |

All of them share the house rules: produce from the back of the centre beam forward, stadium fields floored with goalposts removed, cues anchored to the music, safety arm-then-fire, original work only, and plain words for Rob.
