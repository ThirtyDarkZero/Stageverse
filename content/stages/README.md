# Stage designs (stage kits)

Three original stage designs per venue, offered by the Show Producer / Studio stage picker. `show.json` selects one with `venue.stageKit`.

- `index.json`: venues and their kits, with name, concept, palette, spec and plan paths. This is what the picker reads.
- `<tier>/<stageKit>.json`: the full design, validated by `schema/stage-design.v1.schema.json`: elements (decks, lifts, LED, kinetic pieces, truss, scrims), performer marks, FX positions, cue targets, the act-by-act arc and build notes.
- `<tier>/<stageKit>.svg`: top-down plan, stage at the top.

Generated by `pipeline/tools/stage_designs.py`. Edit the script, not the files; `pipeline/tests/test_stage_designs.py` fails if they are stale.

Coordinates: metres in the venue frame (Z up, stage at -X, audience toward +X), the same frame as each venue's `markers.json`.

| Venue | Kits |
|---|---|
| Club (`club_main_01`, no blockout yet) | Low Ceiling, Tunnel, Cage |
| Theater_Main | False Frame, Staircase, Curtain Machine |
| Arena_Main | Halo, Fault Line, Satellite |
| Stadium_Main (licence pending) | Horizon, Orbit, Monument |

Cue targets: `ledSurfaces` feed the led cue's `surface`, `lightGroups` the lights cue's `group`, `pyroPositions` the pyro cue's `positions`. `kinetics` lists element ids for a new `kinetic` track type (allowed by the timeline schema's forward-compat rule; the cue player needs to learn it). Designs follow the creative director skill in `.claude/skills/stage-creative-director/`.
